BOYFRIEND GIFT WEBSITE

Best phone experience:
1. Extract this ZIP.
2. Keep index.html and i-wanna-be-yours.mp3 in the same folder.
3. Open index.html in Chrome on Android.
4. Keep media volume on and vibration/haptics enabled.
5. Press and HOLD the opening heart. The first touch starts the song and triggers the lub-dub haptic pattern.

Important: in-app previews / embedded browsers may block vibration and/or audio. If that happens, open the extracted index.html directly in Chrome. Browser security does not allow a normal website to force audible autoplay before the first user gesture; this site starts it on the first heart touch, with no separate music button.
